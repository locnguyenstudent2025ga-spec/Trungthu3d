Cẩm nang hướng dẫn chi tiết từng bước đưa dự án **Trung Thu 3D** lên Internet và kết nối cơ sở dữ liệu lời chúc trực tuyến để mọi người cùng truy cập và chia sẻ yêu thương.

## ✦ PHẦN 1: PUBLIC LÊN WEB MIỄN PHÍ VỚI RENDER (onrender.com)

**Render** cung cấp dịch vụ **Static Site miễn phí 100%**, có HTTPS tự động, CDN toàn cầu và tốc độ tải cực nhanh.

### Bước 1: Đưa toàn bộ thư mục dự án lên GitHub
1. Mở Terminal tại thư mục dự án:
   ```bash
   git init
   git add .
   git commit -m "feat: trung thu 3d ready for production"
   ```
2. Tạo một Repository mới trên [GitHub](https://github.com/new) (ví dụ đặt tên: `trungthu3d`).
3. Đẩy code lên GitHub:
   ```bash
   git remote add origin https://github.com/<tên-tài-khoản-của-bạn>/trungthu3d.git
   git branch -M main
   git push -u origin main
   ```

### Bước 2: Tạo Static Site trên Render
1. Truy cập [render.com](https://render.com) và đăng nhập bằng tài khoản GitHub.
2. Tại trang Dashboard, nhấn nút **New +** $\rightarrow$ chọn **Static Site**.
3. Chọn Repository `trungthu3d` vừa đẩy lên.
4. Điền các thông tin:
   - **Name:** `trungthu3d` (hoặc tên bạn thích, web sẽ có dạng `https://trungthu3d.onrender.com`).
   - **Branch:** `main`
   - **Build Command:** Để trống (vì web tĩnh không cần build).
   - **Publish Directory:** `.` (hoặc `./` - thư mục gốc chứa file `index.html`).
5. Nhấn **Create Static Site**.
6. Đợi khoảng 30 giây đến 1 phút, Render sẽ cấp cho bạn một đường link HTTPS trực tiếp (ví dụ: `https://trungthu3d.onrender.com`) để gửi cho bạn bè và người thân trải nghiệm!

*(Ngoài Render, bạn cũng có thể deploy bằng Vercel, Netlify hoặc GitHub Pages với các bước tương tự).*

## ✦ PHẦN 2: KẾT NỐI SUPABASE ĐỂ PHÁT SÓNG REALTIME LỜI CHÚC TOÀN CẦU (KHUYÊN DÙNG)

Mặc định, web đã có sẵn **hơn 24 lời chúc Trung Thu ý nghĩa** và tự động lưu lời chúc của từng người vào `localStorage`.

Khi kết nối với **Supabase** (miễn phí), bạn sẽ có tính năng **Realtime Broadcast WebSocket**:
> **Khi bất kỳ ai trên thế giới gửi một lời chúc**, tất cả mọi người đang mở trang web cùng lúc đều nhận được thông báo tức thì: **Chú Cuội lập tức giật cần câu Cá Chép Vàng bay lên trao ngọc và thắp sáng chiếc lồng đèn mang lời chúc đó thả lên cung trăng theo thời gian thực!**

### Bước 1: Tạo dự án Supabase
1. Vào [supabase.com](https://supabase.com) $\rightarrow$ Đăng nhập $\rightarrow$ Chọn **New project**.
2. Đặt tên dự án (ví dụ: `trungthu3d-wishes`), chọn khu vực gần bạn (Singapore) và tạo mật khẩu.

### Bước 2: Tạo bảng lưu trữ & Kích hoạt Realtime
1. Vào mục **SQL Editor** ở thanh menu bên trái.
2. Dán đoạn mã SQL sau và nhấn **Run**:
   ```sql
   -- 1. Tạo bảng lưu lời chúc
   create table public.wishes (
     id bigint generated by default as identity primary key,
     sender text default 'Người ẩn danh',
     recipient text default 'Tất cả mọi người',
     message text not null,
     client_id text,
     created_at timestamp with time zone default timezone('utc'::text, now()) not null
   );

   -- 2. Bật quyền truy cập công khai (RLS) để web đọc và gửi lời chúc
   alter table public.wishes enable row level security;

   create policy "Cho phép mọi người đọc lời chúc"
     on public.wishes for select
     using (true);

   create policy "Cho phép mọi người gửi lời chúc"
     on public.wishes for insert
     with check (true);

   -- 3. KÍCH HOẠT PHÁT SÓNG REALTIME TOÀN CẦU:
   alter publication supabase_realtime add table public.wishes;
   ```

### Bước 3: Lấy URL & Key dán vào web
1. Vào mục **Project Settings** (biểu tượng bánh răng) $\rightarrow$ chọn **API**.
2. Sao chép:
   - **Project URL** (ví dụ: `https://abcdefghijkl.supabase.co`)
   - **Project API keys** $\rightarrow$ thẻ `anon` / `public`
3. Mở file [assets/script.js](file:///Users/locnguyen/Downloads/tthu3d/assets/script.js) tìm dòng `SUPABASE_CONFIG`:
   ```javascript
   const SUPABASE_CONFIG = window.SUPABASE_CONFIG || {
     url: "https://abcdefghijkl.supabase.co", // Dán URL của bạn vào đây
     anonKey: "eyJhbGciOiJIUzI1NiIsIn...",    // Dán Anon Key của bạn vào đây
     table: "wishes"
   };
   ```
4. Đẩy lại code lên GitHub (`git add . && git commit -m "config supabase realtime" && git push`), Render sẽ tự động cập nhật ngay lập tức!
